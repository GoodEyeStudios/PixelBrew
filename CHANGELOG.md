# Changelog

All notable changes to **PixelBrew** are listed here, newest first.
Every version stays available on the [Releases](../../releases) page — updating
never removes an older download.

## 0.9.0 — 2026-10-18
First public release.

- Drive a USB mini-LCD panel (USB-HID) with your own content, replacing the stock vendor app.
- **PixelBrew logo splash** shown on the panel at startup.
- Sources: test pattern, image, video file, YouTube, live stream (URL/RTSP/HLS),
  screen region, window capture, system monitor (CPU/GPU/disk/network graphs),
  audio spectrum analyzer, clock, weather, slideshow, and a **DLNA cast target**.
- Play **queue** with loop modes, per-item run timers, live countdown, and tray support.
- Rotate in 90° steps, resolution probe, 8 built-in themes + user themes.
- Self-contained single-file build — no .NET install required.
